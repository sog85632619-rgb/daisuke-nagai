# HANDOFF.md — Claude Code / Codex 共通作業台帳

このファイルは Claude Code と Codex がこのリポジトリで協業するための共通作業台帳です。作業を始める前に必ず本ファイルと `CLAUDE.md` を確認してください。

## 運用ルール

1. `work/HANDOFF.md` をCodexとの共通作業台帳として使用する。
2. 作業開始前に、自分の担当範囲と編集予定ファイルを「Active work」に記載する。
3. 相手が担当中のファイルは、調整内容を台帳へ記録するまで編集しない。
4. ユーザーから得た重要な背景、判断、調査結果、変更ファイル、テスト結果を台帳に記録する。
5. 作業完了後は「Completed work」と「Next actions」を更新する。
6. パスワード、APIキー、トークンなどの秘密情報は台帳に記録しない。
7. Codexに任せるのが適切な独立作業があれば、「Next actions」に担当案を明記する。
8. 相手の記録を確認し、重複作業や変更の衝突を避ける。

## プロジェクトの目的・背景

- リポジトリ `sog85632619-rgb/daisuke-nagai` は「ボタンライトゲーム」というシンプルなミニゲーム(素のHTML/CSS/JS、依存なし)を管理している。
- ユーザーは今後、Claude Code と Codex を協業させてプロジェクトを進めたいと考えている。
- 運用方針: **Claude Code が概要・技術構成・開発ルール(`CLAUDE.md`)を主導で作成・維持し、ユーザーがその内容をもとに Codex へ実装指示を出す。** 本ファイルは両者(および指示を仲介するユーザー)が状況を共有するための台帳として使う。
- Claude Code は GitHub 等への直接接続が状況により変動するため、Codexとの連携は基本的に「ユーザーが本ファイルの内容を橋渡しする」非同期の手動リレー方式を前提とする。
