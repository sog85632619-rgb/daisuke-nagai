# 基板実装チェックスキル

入力: **$ARGUMENTS**

## 引数の解析

以下の形式を受け付ける:

```
2SC1815 → BC547
2SC1815 → BC547 VCC=5V
2SC1815 → BC547 VCC=12V Imax=100mA Tmax=85
LM358 → MCP6002 VCC=3.3V
IRF540 → IRF540N VCC=24V Imax=10A
```

- 第1引数: 元部品番号（現在基板に実装されている部品）
- 第2引数: 代替品番号（置き換え候補）
- オプション: `VCC=XX` 電源電圧(V) / `Imax=XX` 最大負荷電流(A or mA) / `Tmax=XX` 最高動作温度(℃)

---

## Step 1: 部品データの読み込み

`parts-substitution.js` の PARTS_DB・PINOUT_DB を Read ツールで読み込み、
元部品と代替品の両エントリを特定する。

見つからない場合は「PARTS_DB に未登録」と通知し、
WebSearch でデータシートを調べて最低限の情報（パッケージ・ピン配置・電源電圧・最大電流）を収集してから続行する。

---

## Step 2: パッケージ互換チェック

### 2-1. パッケージ種別の比較

| チェック項目 | 判定基準 |
|------------|---------|
| フットプリント一致 | 両部品の `specs.package` に共通するパッケージがあるか |
| 搭載向き | SMD ↔ DIP のような変換が必要か |
| 放熱要件 | TO-92 → TO-220 など放熱設計が変わるか |

**判定**:
- ✅ 共通パッケージあり → 基板変更不要（フットプリント）
- ⚠️ 近似パッケージあり → アダプタ/ランド拡張で対応可能
- 🔴 完全に別パッケージ → 基板改版が必要

### 2-2. 実装面積・高さの確認（WebSearch）

パッケージが異なる場合は外形寸法を調べ、既存ランドへの収まりを評価する。

---

## Step 3: ピン配置チェック

PINOUT_DB を参照して両部品の `pinoutId` を比較する。

### 3-1. 判定ロジック

```
同一 pinoutId → ✅ ピン完全互換（そのまま差し替え可能）
異なる pinoutId → 各ピンの機能を比較
  └─ 全ピン機能一致 → ⚠️ 配線順が異なる（基板反転・ジャンパで対応可能な場合あり）
  └─ 機能不一致あり → 🔴 ピン非互換（要基板改版）
```

### 3-2. ピン対応表の出力

ピン配置が異なる場合、以下の形式で差異を示す:

```
ピン対応表（元部品 → 代替品）
┌──────┬───────────────┬───────────────┬────────────┐
│ 機能 │ 元部品ピン番号 │ 代替品ピン番号 │ 対応方法   │
├──────┼───────────────┼───────────────┼────────────┤
│  E   │      1        │      3        │ 配線要変更  │
│  C   │      2        │      1        │ 配線要変更  │
│  B   │      3        │      2        │ 配線要変更  │
└──────┴───────────────┴───────────────┴────────────┘
```

---

## Step 4: 電気的スペックチェック

### 4-1. 電源電圧

| チェック | 条件 | 判定 |
|---------|------|------|
| 最大定格 | 代替品の電源電圧最大定格 ≥ 設計VCC | 🔴 不足なら実装不可 |
| 最小動作電圧 | 代替品の最小動作電圧 ≤ 設計VCC | 🔴 未達なら動作不可 |
| マージン | (最大定格 − 設計VCC) / 最大定格 × 100 | ⚠️ 20%未満は警告 |

### 4-2. 電流

| チェック | 条件 | 判定 |
|---------|------|------|
| 最大定格電流 | 代替品の最大電流 ≥ 設計Imax | 🔴 不足なら実装不可 |
| デレーティング | 代替品の最大電流 × 80% ≥ 設計Imax | ⚠️ 80%ルール未達は警告 |
| 元部品との比較 | 代替品が元部品より低い場合 | ⚠️ 注意喚起 |

### 4-3. 動作温度

| チェック | 条件 | 判定 |
|---------|------|------|
| 最高動作温度 | 代替品のTmax ≥ 設計Tmax | 🔴 不足なら実装不可 |
| 最低動作温度 | 代替品のTmin ≤ 設計Tmin（指定時） | 🔴 不足なら実装不可 |

### 4-4. カテゴリ固有チェック

**トランジスタ (NPN/PNP)**:
- VCEO: 代替品 ≥ 元部品（電圧降格は🔴）
- IC_max: 代替品 ≥ 元部品 × 80%
- hFE 範囲: 大幅に異なる場合はバイアス抵抗の再計算を⚠️警告

**オペアンプ**:
- 帯域幅(GBW): 代替品が元部品より大幅に低い場合⚠️
- スルーレート(SR): 代替品が元部品より低い場合⚠️
- 入力バイアス電流: 桁が大きく違う場合⚠️（CMOS→Bipolarなど）

**MOSFET**:
- VDS_max: 代替品 ≥ 元部品
- ID_max: 代替品 ≥ 元部品 × 80%
- RDS(on): 代替品が高い場合は発熱増大を⚠️警告
- VGS(th): 駆動回路のロジックレベルで確実にオンできるか確認

**ダイオード**:
- VRRM: 代替品 ≥ 元部品
- IF_avg: 代替品 ≥ 元部品 × 80%
- VF: 顕著に異なる場合は回路定数への影響を⚠️警告

---

## Step 5: 総合判定と対処方法

### 判定レベル

| 記号 | 意味 | 対応 |
|------|------|------|
| ✅ | 問題なし | そのまま差し替え可 |
| ⚠️ | 要注意 | 確認・調整が必要だが実装可能 |
| 🔴 | 実装不可 | 基板改版または別部品を選択 |

### 実装可否サマリー

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 基板実装チェック結果
  元部品: XXXXX  →  代替品: YYYYY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
パッケージ:   ✅ / ⚠️ / 🔴
ピン配置:     ✅ / ⚠️ / 🔴
電源電圧:     ✅ / ⚠️ / 🔴
電流定格:     ✅ / ⚠️ / 🔴
動作温度:     ✅ / ⚠️ / 🔴
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
総合判定: ✅ 即時差し替え可 / ⚠️ 条件付き可 / 🔴 実装不可
```

### 対処方法の提示

問題がある場合、具体的な対処方法を提示する:

- 🔴 ピン非互換 → ピン対応表を示し、ジャンパ配線またはランド加工の指示
- 🔴 電圧不足 → 必要な最小定格を明示し、PARTS_DB から条件を満たす別候補を提案
- ⚠️ バイアス再計算 → 変更が必要な抵抗値の計算式を提示
- ⚠️ 放熱設計変更 → 必要な熱抵抗・放熱器サイズの目安を提示

---

## 出力形式

1. **実装可否サマリー**（上記フォーマット）
2. **ピン対応表**（ピン配置が異なる場合のみ）
3. **スペック比較表**

| 項目 | 元部品 | 代替品 | 判定 |
|------|--------|--------|------|
| パッケージ | TO-92 | TO-92 | ✅ |
| ピン配置 | E-C-B | C-B-E | 🔴 |
| 電源電圧 | 50 V | 45 V | ⚠️ |
| ...      | ...  | ...   | ... |

4. **対処方法リスト**（⚠️/🔴 の項目について）
5. **代替候補の提案**（🔴 判定で実装不可の場合）
